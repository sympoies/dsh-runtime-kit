## 2026-08-21 - Main Agent Mode completed on nils-cli 1.27.1

**Result**

- DSH Main Agent Mode now owns controller-only lane launch, authenticated
  readiness, per-lane checkpoints, supervision, request-changes and acceptance
  decisions, and run closeout through the nils-cli coordination store.
- The compatibility boundary now requires and validates the released nils-cli
  v1.27.1 bundle, including the lane-orchestration command family and live

  controller retains orchestration tools and bounded lifecycle ownership.

## 2026-08-21 - Native DSH runtime migration completed

**Result**

- The public out-of-tree runtime kit reached `main` through PR #26, with the
  final parity evidence and migration state repair following in PR #27.
- DSH now uses dsh-runtime-kit plus nils-cli while Codex and Claude Code retain
