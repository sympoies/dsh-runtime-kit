## 2026-08-28 - Unblock dsh-TUI 0.9.3 with an authenticated package patch

**Result**

- The 0.9.3 promotion no longer waits for an upstream release. Runtime-kit now
  owns a temporary installed-package patch that moves history-lock retries off
  the prompt submission stack.
- The patch lifecycle binds the exact package name and version, published
  `package.json` bytes, patch artifact digest, and target before/after hashes.
  It emits typed, idempotent check/apply/reverse receipts and rejects unknown,
  drifted, partially patched, or symlinked targets.
- The authenticated Agent Console smoke installs the exact registry artifact,
  applies the reviewed package patch, proves prompt history returns promptly
  while another process holds the lock, and only then boots the TUI.
- The upstream repair remains tracked for eventual removal of the downstream
  patch, but upstream merge and publication are no longer promotion blockers.

**Why / context**

- The published 0.9.3 history path performs up to 500 synchronous
  `Atomics.wait` retries before dispatching input. A contended history file can
  therefore make both typing and command submission appear frozen even though
  the Agent Console connection and DSH agent are healthy.
- The narrow package patch retains the existing best-effort history behavior,
  stale-lock handling, retry limit, and file format. Only lock acquisition and
  retry waits become asynchronous, and retry timers are unreferenced so they
  cannot delay process exit.

**Evidence**

- Against the authenticated 0.9.3 npm tarball, a fresh held lock made the
  unpatched `appendHistory()` return after 3,584 ms. The exact patched artifact
  returned in 0.33 ms under the same condition.
- The patch lifecycle regression first failed because no TUI patch owner
  existed. The focused lifecycle/profile suite now passes 15/15 and strict
  typechecking succeeds.
- The checked-in artifact is bound to the published tarball's exact
  `history.js` before hash and the reviewed nonblocking after hash; the smoke
  also rejects startup if the installed package cannot produce a patched
  receipt.
