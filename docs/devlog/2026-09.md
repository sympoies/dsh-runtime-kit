# Development log - 2026-09

## 2026-09-01 - Moved restricted reviewer authority into DSH

**Result**

- Added a version- and revision-authenticated DSH patch that provides trusted,
  immutable restricted roles with host-owned admission, cancellation, draining,
  structured result validation, and exact execution receipts.
- Runtime-kit now retains reviewer routing and synthesis while delegating role
  identity, child containment, and capacity enforcement to the DSH host.
- Ordinary subagent starts remain caller-configurable and cannot claim a trusted
  role or inherit its authority.

**Why / context**

- Runtime-local reviewer classification and semaphore state could not prove that
  the same authority applied across direct tools, Code Mode, scoped structured
  output, cancellation, and teardown.
- The new boundary mounts the parent preset and workspace before publishing the
  child, then applies a fixed persona, read-only sandbox, never-approval mode,
  tool restrictions, no-delegation guard, and output schema as one host-issued
  role.

**Evidence**

- A pre-edit probe failed all seven role-ownership assertions against the
  accepted DSH baseline.
- Focused DSH suites pass on rc.7, rc.8, and rc.2 with 242, 248, and 250 tests,
  respectively; runtime-kit passes its complete 753-test suite, type checking,
  and policy benchmark.
- All three pinned patches completed pristine-to-patched-to-pristine manager
  lifecycles. The selected rc.2 row rebuilt successfully in both states; the
  patched packed smoke exercised a real reviewer lane and project skill
  precedence, and the unpatched CLI boot smoke remained healthy.
