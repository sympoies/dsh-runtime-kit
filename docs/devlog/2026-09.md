# Development log - 2026-09

## 2026-09-02 - Bound non-repository shell delegation to one exact operation

**Result**

- Linux advisory and off sessions may complete an exact `pwd` started outside
  Git without blocking the turn. DSH classifies that spelling through the
  lookup-independent system executable and materializes the equivalent
  foreground cwd result without shell lookup or argument mutation.
- Each operation is classified independently against its actual workdir and
  exact command. Baseline metadata, another concurrent command, editor calls,
  absolute repository writes, malformed requests, and every command outside
  the closed system-`pwd` form remain authoritative or fail closed.
- Repository workdirs keep independent capability ledgers. Turn stop checks the
  session-header repository before every operation repository and releases all
  opened identities only after every verdict allows completion.

**Why / context**

- Live Agent Console acceptance from the operator home proved that principal
  authentication was fixed, but the first `pwd` still attempted to open a Git
  repository finish-line. The prior broad repository error then collapsed to
  `finish-line-unavailable`, producing repeated `turn blocked` messages and a
  terminal same-turn error.
- Review showed that treating a non-Git cwd as authority for an arbitrary Bash
  string would allow absolute writes into another repository. A second review
  showed that bare `pwd` can be shadowed by an imported shell function.
- Final adversarial review also found that one session-wide ledger let a normal
  workdir transition poison the turn and let the first operation repository
  replace the header repository at stop. Per-identity ledgers and header-first
  stop aggregation close both paths.

**Evidence**

- Focused regressions cover process/request cwd agreement, bare and partial Git
  boundaries, absolute writes, Git output options, untrusted executables,
  imported-name resolution, null requests, concurrency, and no-tool stops.
- The nils affected suite passed 389 tests plus formatting, lint, clippy, and
  doctests. DSH's focused finish-line, client, and plugin-contract suite passed
  177 tests after the operation-boundary repair.
- The signed nils-cli 1.27.34 Linux and macOS release artifacts were promoted
  into the compatibility contract. The selected pristine DSH rc.2 checkout
  completed patch application, host rebuild, packed keyless smoke, reversal,
  pristine rebuild, and authoritative unpatched smoke with a clean final tree.
- The complete runtime-kit package suite passed 774 tests; type checking and
  both the in-process and released-helper policy benchmarks also passed with no
  retained child or active-handle leaks.
- API-contract, security, maintainability, and red-team review found no
  remaining actionable issue after the closed absolute-system-`pwd` repair.
